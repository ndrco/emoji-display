# emoji_editor.py

Графический редактор 8×8 анимаций для `emojis.h`.

## Запуск

```bash
cd max7219_emoji_panel
python3 emoji_editor.py
```

Если в системе нет Tkinter:

```bash
sudo apt install python3-tk
```

Можно явно указать файл и актуальную цифру Flash из Arduino IDE:

```bash
python3 emoji_editor.py --file ./emojis.h --flash-used 10466
```

## Что умеет

- открывать и сохранять `emojis.h`;
- редактировать 1–4 кадра для каждого эмодзи;
- задавать индивидуальный FPS;
- показывать Unicode emoji reference;
- подставлять имя по Unicode/CLDR-названию;
- приблизительно оценивать Flash;
- сохранять строки/столбцы во временном виртуальном буфере при сдвиге кадра;
- сбрасывать изменения текущего кадра кнопкой `Отменить`;
- сохранять текущий эмодзи кнопкой `Сохранить` с очисткой виртуального буфера;
- проигрывать анимацию текущего эмодзи кнопкой `Play`.

Оценка памяти приблизительная: редактор считает размер данных эмодзи во Flash (`имя + кадры + строка таблицы AnimDef`) и добавляет его к базовой оценке скетча из последней компиляции.
